# من اسمه نصيب — محرك الاسم ← الموضوع ← الاقتباس

نادي علوم البيانات · جامعة اليمامة · اليوم العالمي للغة العربية

الموقع: https://dsc-name-quote.vercel.app (صفحة الزائر، و`/game.html` للعبة «شاعر أم آلة؟»).
تريد المساهمة؟ ابدأ من [CONTRIBUTING.md](CONTRIBUTING.md).

```
الاسم ← تطبيع ← مركّب؟ (عبد… / …الدين) ← القاموس ← الجذر ← «اختر ما يشبهك»
                                                          ↓
                                       موضوع ← اقتباس ثابت (نفس الاسم = نفس الاقتباس)
```

## التشغيل
```bash
git clone https://github.com/AmrShaar13006/dsc-name-quote.git
cd dsc-name-quote
npm test          # يبني البيانات ويتحقق منها ويصدّر نسخ المراجعة ثم يشغّل 52 اختبارًا
npm run ui        # يبني ui/index.html (صفحة الزائر) وui/test.html (واجهة الاختبار)
npm run serve     # معاينة محلية على http://localhost:5173
npm run report    # دقة استخراج الجذر على أسماء القاموس
```
بلا مكتبات خارجية. يحتاج Node 18 أو أحدث. تعليمات العمل على المشروع مع Claude Code في `CLAUDE.md`.

## الاستخدام
```js
import data from './src/data.js';
import { createEngine } from './src/engine.js';
const engine = createEngine(data);
const r = engine.resolve('عبدالرحمن');
// { source:'compound', canonical:'عبدالرحمن', meaning:'المتعبّد لله باسمه «الرحمن»', root:'ع-ب-د', themes:['rahma','iman'], ... }
const q = engine.quoteFor(r);            // { id, first, second, author, url, themes }
const q2 = engine.quoteFor(r, 'iman', 1); // موضوع آخر، و«بيت آخر» بالإزاحة 1
```
قيم `source`:
- `dictionary` و`compound`: المعنى مراجَع.
- `root`: معنى تقديري من الجذر.
- `choose` و`latin`: نعرض 3 مواضيع يختار منها الزائر.
- `empty`: لم يُكتب اسم.
- `blocked`: كلمة من `data/blocked.csv` (شتيمة أو لفظ مسيء)، فلا تُكتب على البطاقة. لا يُطبَّق على أسماء القاموس.

## دورة المراجعة
1. يراجع المراجِع ورقة «القاموس» وورقة «الاقتباسات» في الجدول.
   في «الاقتباسات» يغيّر «الحالة» إلى معتمد أو مستبعد. المستبعد لا يدخل البناء.
2. ينزّل كل ورقة بصيغة CSV.
3. `node scripts/import-review.js ~/Downloads/الورقة.csv` لكل ورقة. يتعرّف على نوعها من العناوين، ويرفض الملف ويذكر السطر إن وجد خطأ.
4. `npm test`

## الاقتباسات
أبيات مختارة يدويًا من «ويكي مصدر» (ar.wikisource.org)، لشعراء انقضت حقوق شعرهم، ومحفوظة في `data/quotes.csv` بنصها كما في صفحة القصيدة، مع اسم الشاعر ورابط القصيدة.
لا نحفظ نصوص موقع الديوان: شروطه تمنع حفظ محتواه أكثر من 24 ساعة.
لإضافة أبيات: اكتب المرشحات في CSV (`first,second,author,themes`) ثم `node scripts/wikisource.js find <الملف> <نتيجة.json>`، وخذ ما طابق تمامًا عند الشاعر نفسه.
`node scripts/wikisource.js check` يعيد التحقق من كل الأبيات.
شروط الاختيار: بيت واحد كامل، معنى إيجابي، لا غزل ولا رثاء ولا هجاء، لا أخطاء طباعية، صيغة تناسب الجميع.
البناء يرفض: رابط الديوان أو أي رابط غير ويكي مصدر، شاعرًا فارغًا، تشكيلًا مكررًا، حرفًا فارسيًا، وموضوعًا فيه أقل من 3 أبيات.

## الملفات
| الملف | المحتوى |
|---|---|
| `data/names.csv` | 357 اسمًا (منها 91 خليجيًا مضافًا بعد البحث): المعنى والجذر والمواضيع والثقة والمصدر في الملاحظة |
| `data/roots.csv` | 187 جذرًا للأسماء غير المعروفة، كلها بمعانٍ إيجابية غير ملتبسة |
| `data/divine.csv` | أسماء الله الحسنى للأسماء المركّبة (عبد…). مركّبات «X الله» مثل ضيف الله تُعالج في المحرك |
| `data/themes.csv` | 14 موضوعًا |
| `data/blocked.csv` | كلمات لا تُكتب على البطاقة. تدخل الصفحة كبصمات (hash) لا كنصوص |
| `data/machine.csv` | 34 بيتًا كتبها Claude للعبة «شاعر أم آلة؟»، مشكولة شكلًا تامًا، والبناء يفحص وزن كل بيت |
| `src/prosody.js` | مدقق العروض: يقطّع الشطر المشكول ويطابقه بتسعة بحور |
| `ui/game.template.html` | لعبة «شاعر أم آلة؟» (يُبنى منها `ui/game.html`) |
| `data/quotes.csv` | 76 بيتًا من «ويكي مصدر» لـ27 شاعرًا، من 5 إلى 17 بيتًا لكل موضوع |
| `data/attributes.csv` | «ما يستوحيه الاسم من صفات»: تأويل أدبي من معنى الاسم المراجَع (لا من جذره)، يظهر على البطاقة نفسها |
| `data/figures.csv` | «شخصيات تاريخية تحمل اسمك»: مطابقة تامة للاسم، بصفحة مستقلة (`ui/figures.html`)؛ لا صورة أبدًا لشخصية دينية |
| `scripts/wikisource.js` | يبحث عن الأبيات في ويكي مصدر ويتحقق منها حرفًا بحرف (`find` للمرشحات، `check` لإعادة فحص الأبيات) |
| `src/engine.js` | المحرك |
| `ui/index.template.html` | صفحة الزائر: الاسم ← البطاقة ← صورة PNG (يُبنى منها `ui/index.html`) |
| `ui/test.template.html` | واجهة الاختبار للفريق (يُبنى منها `ui/test.html`) |
| `ui/poster.html` | ملصقات بأزرار تنزيل لكل تجربة: شريحة للشاشة 16:9 وملصق طباعة A4. ملصق «من اسمه نصيب» فيه بطاقة حقيقية مثالًا، وملصق «شاعر أم آلة؟» (`poster.html#game`) فيه جولة من اللعبة |
| `qr/` | رموز QR (SVG وPNG، بشعار النادي وبدونه): `dsc-name-quote-qr` للموقع و`dsc-game-qr` للعبة «شاعر أم آلة؟». تُولَّد بـ `python scripts/make-qr.py [المجلد] [الرابط] [الاسم]` |
| `src/data.js` | مولَّد تلقائيًا، لا يُعدَّل يدويًا |

## النشر
يتولاه عمرو من حساب النادي على Vercel (`npx vercel --prod`) بعد دمج التعديلات في `main` ونجاح الاختبارات.
يبني Vercel الموقع بـ `npm run build && npm run ui` وينشر مجلد `ui/`. الموقع ثابت بالكامل (static)، فلا يحتاج أي دوال خادم (serverless functions)، وهذا يناسب خطة Vercel المجانية.
